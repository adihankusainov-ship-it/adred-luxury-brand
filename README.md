# ADRED

Люксовый сайт бренда одежды ADRED.

## Как запустить локально

1. Откройте терминал в папке проекта.
2. Запустите локальный сервер:

```bash
python3 -m http.server 8000
```

3. Откройте в браузере:

```text
http://localhost:8000
```

## Структура проекта

- `index.html` — структура страницы
- `styles.css` — стиль и визуальный дизайн
- `script.js` — небольшая логика для мобильного меню и года в футере
